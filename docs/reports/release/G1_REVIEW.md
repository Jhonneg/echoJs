## How to review a song

1. Open `/audio-lab.html` on the ECHO development server. Under **Choose local review audio**, select a permitted browser-supported file. The “Review file selected locally” message confirms the selection; playback waits for **Play / resume local audio**. Pause and that same Play button resume the selected element; Stop releases it.
2. Start in **Compare**. Orange shows legacy levels/continuous accents; cyan shows fixed candidate energy/events/context. Both paths receive the same input and gain. **Legacy / Candidate** only change presentation. The same 0–1 display range does not mean the two transfer curves should produce equal values; judge contrast and musical usefulness.
3. Candidate squares hold for 200 ms after actual emission, with strength/count/time beside them. The hold is only a display aid. Peak/decision latency is not hidden by backdating. Displayed emission times are performance-clock seconds, not song position. Reduced motion suppresses brief markers while retaining counts and measurements.
4. Listen to a few short passages covering quiet/loud bass, sustained drone, weak/strong rhythmic attacks, sparse/mid/high content, quiet ambience and active silence. Use the existing isolated generated fixtures as known band controls. Pause/Stop clearing is a separate lifecycle check from decay through an actual silent passage.
5. For source parity, play equivalent permitted material in an owner-controlled player tab and use **Share a tab**, enabling native tab-audio sharing. Keep explicit player gains/ECHO local volume matched and check raw RMS on a sustained passage. OS listening loudness alone does not prove matching analyser levels. Allow capture timing/resampling differences; mark parity pending if equivalent input cannot be established. Confirm source sound continues once, native Stop sharing cleans up and retry works.

Selecting a file or sharing a tab locks JSON/CSV exports, including previously loaded synthetic reports. These controls never export live review audio/features. Stop/replacement releases local object URLs and capture tracks; the file chooser is cleared. No recording, upload, provider integration, automatic review history or live metric persistence is added. The agent's automated checks use generated audio only; the owner reviews actual music without agent inspection of private media/readouts/screenshots.
